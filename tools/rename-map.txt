# The rename table: every old pocketvj / pvj name and its new name, the one source of truth for the rename
# (rename-pvj-assessment.md, PR 1; decision D135). tools/rename-apply.py reads it; tests/test_old_names.py checks it.
#
# One row a line, four fields separated by tabs: old, new, kind, note. Lines starting with # are comments.
# Kinds, one per pull request of the plan:
#   text      the product word in prose (PR 3)
#   protocol  OSC, header, cookie, browser keys and globals (PR 4)
#   render    the C renderer and the names it shares with the player (PR 5)
#   package   the Python package pvj to mctl and names inside it (PR 6)
#   system    units, accounts, the shared group, folders, commands (PR 7)
#   release   update bundles, signing, USB names (PR 8)
#   env       environment variables (PR 8)
#   ci        workflow, runner, image and job names (PR 10)
#   keep      a phrase that never changes (the credit, upstream addresses); new is the same as old
#
# Prefixes: nxlx for what an admin sees on a node, mctl for what a performer, a device or other software sees.
# The shared service group is nxlx-svc (node-01 already has a login group called nxlx).
#
# How a row matches (the same in the apply script and the tests):
#   - Exact, case-sensitive text. The longest row wins where two start at the same place.
#   - A row that starts with a letter, digit or _ does not match after one of those (so "xpvj" and
#     "test_pvj_x" are not touched by "pvj..."). A row that starts with / also does not match after one of those
#     or after a dot (so "../pvj" and "code/pvj" are paths, not OSC addresses).
#   - A row that ends with a letter, digit or _ does not match before one of those or before a dash (so
#     "pvj-ndi" does not take "pvj-ndisc", and ":pvj" does not take ":pvj-ndi").
#   - A row ending in * is a family: the rest of the name (letters, digits, _) is kept, so "PVJ_*" turns
#     PVJ_RUNTIME_DIR into NXLX_RUNTIME_DIR.
#   - "pvj" on its own is ambiguous (package, group, prose) and has no row: the apply script reports such places as
#     not covered, and a later pull request adds a row with enough context.
#   - Never search for the new name mctl without a word boundary: systemctl contains it.
#
