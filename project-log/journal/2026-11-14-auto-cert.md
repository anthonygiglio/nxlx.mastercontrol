## 2026-11-14, Automatic node certificates (D139)

- The owner chose "Fully automatic" HTTPS for new nodes. The first look found that every root made by `boxcert.py` (his too, made 2026-10-13) is `pathlen:0`, so no signer can sit under it; he chose a new root (option A).
- Built: `make-root` with `pathlen:1`; `make-signer`; `move-root` (a message the old root signs, so nodes move to the new root with nobody at them); `tools/nxlx-signer.py` (the signing service: .local names and the caller's own private address, first-come pins, rate limit, log) with a Windows logon task and a systemd unit; `pvj/autocert.py` on the node (start, every six hours, ten minutes while waiting); `install.sh --signer` and `--root-fingerprint`; an "Automatic certificate" card on System > Secure connection; docs/HTTPS.md "Automatic certificates" with the one-evening steps.
- Fixed for a chain through a signer: a certificate file keeps the signer; a signer is never pinned as the root (the first CA in a file used to be taken as the root); the root check passes signers as untrusted; peers verify the chain in the handshake.
- Tested: `tests/test_autocert.py` (22 tests) and the https, boxcert, peer, handover, fleet list modules. The service also ran on Windows Python 3.12 with Git's openssl against a throwaway root.
- An independent review found two High, six Medium and six Low problems (addresses not pinned, a first root taken from whoever answered, a pin file that failed open, the system CA folder trusted by `openssl verify -CAfile`, no Host or Origin checks, among others). All are fixed with tests in `tests/test_autocert_review.py`, and the reviewer's attack script now fails at every step (two of its diagnostic prints assumed the old behaviour and were guarded in a copy). D139 says what changed.
- The FireTab launcher (its own local repo) now accepts a node certificate from a bundled signer that the bundled root signed; not built or installed.
- Not tested: a real node, a real phone, the Windows logon task, the HP answering as `yt-1300f.local` to a node, and the FireTab launcher, which needs its own change (D139).
