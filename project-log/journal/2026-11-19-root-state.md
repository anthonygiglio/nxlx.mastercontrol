## 2026-11-19, J-178: root's files moved out of the panel's state folder

- The problem: /var/lib/nxlx belongs to the panel account nxlx-web and has no sticky bit, so that account can rename any name in it, root's files included. It could hide root's update backups (backups/) before a factory reset and put them back after it, so a later rollback restored the old devices and passwords. The clip stick's claim record (clip-stick.json) could be replayed the same way.
- The fix: both now live in /var/lib/nxlx-update, root:root 0700, beside the panel's folder (mctl/paths.py ROOT_STATE_DIR). Settings copies are settings-<version>-<time>.json directly in it, the claim is clip-stick.json. The panel's public label file (clip-stick-label.json) and node-id stay in the state folder.
- mctl/update.py: Updater(root_state_dir=...), backup_dir() is that folder; _open_backups(create) opens it with O_NOFOLLOW|O_DIRECTORY and needs a folder of this user that nobody else can write. Its parent is root's, so the old set-aside logic is gone: a link, a foreign owner or a loose mode there is a fault, reported, nothing renamed or followed.
- migrate_legacy_state(): runs at the start of apply and rollback, and from install.sh (nxlx_state_fix, after nxlx_fd_own makes the new folder). Descriptor-relative from the state folder: the old backups folder is opened O_NOFOLLOW|O_DIRECTORY; a link or non-folder, or a folder not root's or writable by others, is renamed aside and its contents never used. Each file is taken only if it is a plain file of root's, one name (st_nlink 1), mode without group or other bits, within a size limit; it is copied into the new folder (O_EXCL, mtime kept) and then unlinked from the old one. clip-stick.json is moved by the same rules, and dropped if it is a link, loose or not JSON. A name already in the new folder is never overwritten. Problems are logged, not raised.
- mctl/clipstick.py: read_record(root_dir), write_claim(..., root_dir=), forget_claim(state_dir, root_dir); claimed_label no longer falls back to the record (the panel cannot see root's folder). mctl/usb.py reads NXLX_ROOT_STATE_DIR (default paths.ROOT_STATE_DIR). mctl/sysd.py clear_update_backups empties the new folder (backup_folder).
- install/nxlx-sysd.service ReadWritePaths names -/var/lib/nxlx-update. docs: MANUAL, install/README, HANDOFF.
- Tests: test_update (new folder, refused link and loose folder, eight migration tests), test_clipstick, test_sysd, test_install, test_output; tests/real_install_test.sh checks the new path and that an old link at backups is set aside, not followed. real_install_test.sh was edited but not run here.
- Not done: the factory reset still leaves the claim (it is the node's pairing with its stick, not a device or password). nxlx-sysd clears only settings-*.json.
