## 2026-11-14, the nine waits in the panel test that never waited

- tests/ui/panel.test.js had nine `page.waitForFunction(async () => ...)` waits on the graphics card (text size, motion, anchor, logo). Playwright polls a function until it returns something truthy; an async function returns a Promise, which is truthy at once, so every one of them was over on its first look.
- New tests/ui/poll.js has `until(page, check, timeout)`: one page.evaluate per poll, 100 ms apart, throws with the check's text and its last value on timeout. The nine waits use it with their own 8000 ms.
- New tests/test_ui_waits.py fails when any tests/ui/*.js has `waitForFunction(async`. It runs with the unit tests.
- Run locally twice (Playwright 1.56.1, WSL): both runs went through all nine waits with none timing out, so the old tests were not passing by luck. Run 1 later died on an unhandled "Route is already handled" in the remote-device route near line 2566; run 2 failed in the strobe `steady` check near line 5060 (position 0.4 s, local mpv timing). Neither is touched by this change; not checked on master.
