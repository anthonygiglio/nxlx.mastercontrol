## 2026-11-10, Show stats on output (D133)

- Built the Owner's debugging overlay: `pvj/statsoverlay.py`, `POST` and `GET /api/stats-overlay` (role full, studio-only), an Owner switch with a corner choice on the Screen output card, `Ipc.batch` (many questions, one connection), `throttled` in `pvj-sysd`, and `osd-overlay` on `pvj-render` (0.12.0, capability flag `osd-overlay` in the `pvj-render` property, a bitmask that keeps the text layer on, id 0 to 63, text 4096 bytes at most, no `compute_bounds`). It draws with mpv's `osd-overlay` (ASS), in its own id, never `show-text`, so a PIN or recovery code is never replaced. Classic mpv gets `--load-stats-overlay=no`.
- It shows: the node's name and address; the output rate and dropped frames (classic: the clip's frame rate and drops a second; New renderer: flips a second against the output rate, missed vblanks a second, the clip's rate and drops, and the shaders' late frames); decoder (`hwdec-current`), size, pixel format and the clip's file name; CPU (from `/proc/stat` deltas), memory and temperature; throttling in words (under-voltage now, capped now, throttled now, and has throttled since boot), from the helper every 5 seconds, "throttling: unknown" without it.
- Tests: `tests/test_statsoverlay.py` (escaping, the lines, the sampler's rates with a fake clock, every show-safety rule, `Ipc.batch` against a socket, classic mpv itself, the routes through the real Api including an import that tries to turn it on, the helper's command), the render tests (draws in its corner and nothing outside it, `none` removes it, a show-text that ends does not take it, bad ids, formats and sizes refused), the unit file, and the panel test at 390, 820 and 1440.
- What the research got wrong (it needed a change to build): `pvj-sysd` runs with `PrivateDevices=yes`, and `/dev/vcio` is root-only, so `vcgencmd get_throttled` could never have worked under the unit as it was. The unit now has `DevicePolicy=closed` and `DeviceAllow=/dev/vcio rw` instead (checked on both nodes: `/dev/vcio` is `crw-------`, there is no `get_throttled` file in sysfs on the 6.18 kernel, and `vcgencmd` as the node's user fails). It is untested on a node: the update must restart `pvj-sysd` with the new unit. A cpufreq reading under the top speed is not "capped" on its own (both nodes use the `ondemand` governor, so an idle Pi sits low): it counts only when the CPU is busy (70 percent or more) and under 85 percent of its top speed, or when `scaling_max_freq` is under `cpuinfo_max_freq`. The mpv arguments are built in `Player.mpv_command` (the research said player.py:335-350). `clean_hostname` already strips a name to letters, digits and `._-`; the ASS escaping is there for the file name and as a second guard.
- Not done: nothing was deployed or run on a node; the overlay has not been seen on a screen (only pixels in a headless render and mpv with no output). The cost on the Pi 3B has not been measured: by design it is one connection a second, three small file reads and one helper call every 5 seconds, and nothing at all while off.
