## 2026-11-22, Review fixes for the QR sticker (J-179 slice B, PR 322)

- Visitors have their own budget (half of each node-wide window: 15 in 10 minutes, 100 a day), counted apart, and hold at most half of the kept list (the oldest visitor note goes, never a signed-in one). Tests include the review's three-address scenario and twenty addresses over a day.
- A note of a role this release does not know is kept in the file untouched and not shown, so a later release's notes survive a rollback to this one; a rollback to a release before this change still loses visitor notes (said in the addendum).
- The access log names no address for `GET /feedback`, `/feedback.html` and `POST /api/feedback/visitor`; the page is refused through the support tunnel like the send.
- The sticker is made only for the node's own host names and interface addresses (localhost in any form, `0.0.0.0`, `::` and mapped loopback are refused with plain words).
