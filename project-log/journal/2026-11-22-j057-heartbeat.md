## 2026-11-22, J-057 the daily heartbeat

- The owner decided that the alpha should push to his phone when a node goes quiet. Detecting silence needs something outside the node, so the node's half is built and the service stays the owner's to choose: `mctl/heartbeat.py` pings an https address he pastes on Setup > Health (Heartbeat card), on an interval of 5 to 60 minutes (15 by default), from its own thread with a short timeout. Off by default; works with any service that takes a ping URL; healthchecks.io is named as one example in `docs/HEARTBEAT.md`, which also has the steps (period 15 minutes, grace 60, phone, paste, test). Decision D149 (D146 to D148 are taken by open pull requests).
- Patterns followed: the Owner's route and policy rows as the time zone's (J-129): `GET /api/heartbeat` (the address masked), `POST /api/heartbeat`, `POST /api/heartbeat/test`; both POSTs in `support.REMOTE_DENY` and refused again in the handlers; rows in tests/test_roles.py, tests/test_carried_roles.py and tests/test_support_reach.py. The setting `heartbeat` is in `boxcare.BOX_OWN` and in the settings defaults, so it is stored in settings.json like the others, never exported, never set by an import (an import that names it is noted and left), and the diagnostics file shows the address masked. No settings schema change.
- No decision forbids outbound calls; the only other outbound code is the certificate signer client (autocert) and remote support. This one is opt-in and sends only a plain GET, with no redirect following, so a ping cannot leave https.
- Tests (tests/test_heartbeat.py, 49): address check, setting form, the ping against a fake service (success, 404, 500, redirect, timeout, name and certificate errors, a broken reply, any other error: never raises), what a request carries, the real opener against a loopback server (headers, no redirect, timeout), the thread and its tick, the routes for the Owner, Operator, Guest, no sign-in and a support device, the 409 for a second test, the setting kept on disk, export, import and diagnostics. Run with test_roles, test_carried_roles, test_support_reach, test_support, test_boxcare, test_settings, test_timezone and test_old_names. The browser test was not run (no Playwright here); `node --check mctl/web/app.js` passes.
- Not proven: no real service, phone, certificate chain on a Pi or 60 minute grace was tried; the panel card was written and syntax-checked but not looked at in a browser. The owner makes the account and runs step 8 of docs/HEARTBEAT.md (pull the cable, wait for the grace time) once.
