## D146. Projector volume is steps over PJLink class 2, tried and said plainly (2026-11-22)

J-066, alpha slice. A projector takes **volume up and volume down, one step each** (`%2SVOL 1` and `%2SVOL 0`), from `POST /api/projector` (`volume_up`, `volume_down`, for one projector or `all`) and from the Room screen's group card (`POST /api/room/group`, the same two actions), for the Owner and the Operator. A Guest is refused on both routes like mute and the other changes: the guest line (`policy._power`) lets through only on, off and input, and the tests keep it so. The Room screen sends the step now, to every projector of the group, and answers which ones did not take it; it is not a queued step of a scene (a step is not a state to settle, and a scene has no volume: D36's Room plan said so and still holds). OSC gets `/mctl/group/<n>/volume_up` and `/volume_down` (press), the one controller table that names projector actions; MIDI and TouchOSC have no table of projector actions, so nothing was added there.

Why this shape: the class 2 command has no level to read back, so the screen shows steps only and no figure. That the Epson X27 and X39 obey SVOL is **not proven**; the owner's rule is to say so rather than fail silently. So the box tries: if the projector said class 1 when it was identified, nothing is sent; if it answers ERR1, ERR2 or ERRA, or Epson control alone is chosen for it, the answer is "This projector does not take volume from the network". Any other answer keeps its own words (ERR3 "cannot do that right now" in standby, ERR4 a fault). ERRA from the greeting (a wrong password) says the same words for volume, which hides the password cause on this one command; the status line of the same projector still shows it.

Cost / rules out: no volume level or readout; no volume in scenes; no Epson ESC/VP volume (its own protocol, a later add-on in the Phase 2 plan); remote support is not stopped from sending a step (it is harmless and not a picture setting, unlike D99's list). Nothing here has met a real projector.
