## An async function in waitForFunction never waits (2026-11-14)

Playwright's waitForFunction polls until the function returns something truthy. An async function returns a Promise, and a Promise is always truthy, so the wait ends on the first look: a check that could never hold resolved after 36 ms of a 1.5 s timeout. Nine waits in the panel test were written that way and passed without waiting.

What we do now: a check that fetches from the node goes through `until()` in tests/ui/poll.js, which polls one page.evaluate at a time. tests/test_ui_waits.py fails on the old spelling. When a wait is added to a test, make it fail once on purpose and see it time out.
